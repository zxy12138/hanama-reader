# 数据、隐私与备份

## 发布包包含什么

发布脚本只复制应用源码、选定测试、启动和校验脚本、许可证、文档与虚构教程截图。不会复制开发机 Git 历史、小说、聊天记忆、API 配置、日志、模型包、第三方词库、助手文件夹或测试配置。

`SOURCE_AUDIT.json` 记录检查范围；`SOURCE_MANIFEST.json` 记录内容哈希。`npm run release:verify` 复查文本中的常见凭据格式、个人路径、网络身份、PNG/ICO 元数据、禁止文件、文档链接以及文件清单。它不是对任意编码秘密的数学保证。截图还需要人工看一遍。

## 软件运行时保存什么

| 数据 | 位置与注意事项 |
| --- | --- |
| 书籍、屏蔽记录、任务进度、图库/封面资产、配置 | Electron 用户数据目录，默认 Windows `%APPDATA%\hanama-reader`。开发测试或自定义启动可能另设位置。 |
| 布局、阅读显示偏好 | 用户数据中的本地浏览器存储；备份整个用户数据目录才能完整保留。 |
| 模型/绘图凭据 | 本机配置与系统安全存储；迁移电脑或系统账号后可能无法解密，需要重新填写。加密文件也不要公开。 |
| 标签数据库与同步缓存 | 项目 `data/tag-library`；默认不随源码分发。 |
| 助手文件 | 仅使用你主动授权的文件夹。全新安装默认“尚未授权”；设置中可清除授权，不删除文件。旧版已保存的授权会保留，可手动清除。 |
| 原始导入文件和导出 HTML | 你选择的位置，可能在项目目录外。 |

## 哪些内容会发送给服务

阅读、精确规则匹配与一般书架管理在本地完成。启用在线模型后，任务所需的正文片段、全局提示词、角色/服装设定、检索出的相关标签等会随请求发送到所配置的模型服务。绘图会发送提示词、参数和所需参考图给绘图服务。助手请求可包含你确认提供的文件内容。

本地模型使用所配置的本地服务地址；地址若改成远程服务器，则不再是仅限本机。模型是否记录请求、服务端数据保留多久，由各服务方控制。不要把“本地保存”理解成执行在线 AI 任务时完全不出网。

本地词库是应用检索后提供给模型的参考，在线模型不会因此获得数据库或电脑任意访问权。

助手文件夹由你主动选择授权，不会默认授权安装目录。清除授权后，配置中的目录值保存为空，助手对话上下文随之清空；已授权目录中的文件保留。旧版已经保存的路径仍会恢复，若不需要可在设置中主动清除。

## 备份与恢复

1. 暂停任务，等待保存完成，正常退出应用。
2. 复制整个用户数据目录，包括图片资产与本地存储，不要只复制 story.json。
3. 另存标签目录、助手文件夹和原始导入文件。备份放在项目发布目录以外。
4. 恢复前先备份目标电脑现有数据，关闭应用后再放回相应目录；跨版本恢复先用副本验证。
5. 启动后检查书架、插图、阅读位置与任务进度。凭据无法解密时在设置中重新输入。

不要在真实数据上运行清理测试。删除整本书、清空图文或永久删除前，先确认操作范围和备份。

## 分享截图和日志

裁去 API Key、账号、个人路径、私密正文、角色/提示词内容及不希望公开的账单信息。控制台可能保存服务原始返回，不能因为有密钥过滤就默认整份日志适合公开。报告问题优先使用虚构最小示例。
